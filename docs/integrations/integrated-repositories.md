# Integrated Repositories

Third-party repositories and projects integrated into the Agent Guidance MCP codebase.

---

## Bundled Content & Releases

Integrated skills and standards (629 embedded skills total) are curated and bundled directly into the binary and distributed with each release. They are synchronized to `~/.agent-guidance/skills` upon installation/setup and when upgrading via:

```bash
agent-guidance --upgrade
```

| Repository | Role | License |
|---|---|---|
| [ECC v2.0.0](https://github.com/affaan-m/ECC) | Core skill catalog — backend, frontend, testing, security, DevOps, data, research, and 12+ language ecosystems. | MIT |
| [Cloudflare Skills](https://github.com/cloudflare/skills) | 25 skills covering Workers, Wrangler, Durable Objects, Agents SDK, Next.js & frameworks on Cloudflare, Cloudflare One, Sandbox, Turnstile, Security Audit, and Web Performance. | Apache 2.0 / MIT |
| [andrej-karpathy-skills](https://github.com/forrestchang/andrej-karpathy-skills) | 6 core coding principles (Think Before Coding, Simplicity First, Surgical Changes, Goal-Driven Execution, DRY, Code Organization). | MIT |
| [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | UI/UX design data — palettes, fonts, landing patterns, charts, slide strategies. | MIT |
| [anthropics/skills](https://github.com/anthropics/skills) | Creative & design, development & technical, enterprise & communication skill capsules. | Apache 2.0 |
| [OWASP Cheat Sheets](https://github.com/OWASP/CheatSheetSeries) | Security cheat sheets — SQL injection, XSS, CSRF, auth, cryptography, MCP security, AI agent security, and more. | CC BY-SA 4.0 |
| [humanizer](https://github.com/blader/humanizer) | AI writing pattern removal skill (v4.0.0) — strips structural and stylistic AI tells from prose. | MIT |
